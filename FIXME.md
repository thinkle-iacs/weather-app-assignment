# Teacher launch checklist

Search for `FIXME` to find this checklist before assigning the project.

- **FIXME — Template setting:** In repository **Settings → General**, confirm **Template repository** is enabled so this repo can be used as a clean source for the student assignment.
- **FIXME — Pages setting:** In **Settings → Pages**, set **Source** to **GitHub Actions**. Push once and confirm the deployment link works.
- **FIXME — Classroom assignment:** Create the GitHub Classroom assignment from this template and decide whether student repositories should be private.
- **FIXME — Course details:** Add dates, milestone checkpoints, and review the Digital Creation rubric in README.md. It uses Appearance, Function, and API Use as evidence for one overall assessment, with 3/4 descriptors adapted from last year’s rubrics.
- **FIXME — Codespace smoke test:** In a fresh Codespace, run `npm install`, then `npm start`; test ZIP codes `01879`, `02108`, and an invalid value such as `00000`.
- **Starter scope:** The starter intentionally displays raw forecast JSON with browser-default appearance. Students select data and design the interface.

## Rubric models

The README rubric adapts the 3/4 structure and design expectations from [Web Design Portfolio Rubric-25-26](https://docs.google.com/document/d/1yt8v5X_RJzaRUAWmvcmfETiftBDjkA4ZOPdqQPMmHYk/edit) and [Interactive Design Rubric-25-26](https://docs.google.com/document/d/1dbMnIEqORjRvvC6hZyJSqBifUnBCXEiglsPCNTgVbVc/edit), using the teacher's requested Digital Creation grouping. API-specific descriptors are new for this assignment.
