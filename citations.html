At Tom Hinkle's request, OpenAI Codex removed the starter styling and forecast cards, restored raw JSON output, and adapted the assignment rubric from his 25–26 Portfolio and Interactive Design rubrics. Students choose the data to use and design the finished interface themselves. The earlier timestamp formatting code was removed with the cards.
